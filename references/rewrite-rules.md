# 改写规则（Rewrite Rules）— 必做清单

> 模板（resources/template/paper.md、general.md）定义"输出长什么样"，本文件定义"改写时必须做到什么"。两者冲突时**以本文件为准**。

- **Frontmatter 必填** — 按模板顶部 YAML 字段逐字段提炼为一句话，数值必须来自原文，不得机械复制摘要
- **一句话摘要必填** — 正文首块，1 句话写清 对象/器件 → 方法 → 关键结论
- **原文引用规则** — 结果/结论区的每条"主要发现"必须紧邻至少一条真实原文引用；引用必须真实出现在 MinerU MD 或原 PDF；定位不到写「未在当前全文中定位到可核验原句」，严禁根据中文摘要反向生成英文 quote，严禁编造页码
- **公式规则** — 仅原文可靠时保留（公式说明 + 公式 + 公式拆解），乱码/残片不强行解释
- **「我的判断」必填** — 笔记结尾四问（启发/借鉴/追问/关联）必须填写
- **证据分层** — 原文=证据层、笔记=理解层；AI 转述用普通正文、原文引用用引用块 `>`；无法核验的内容标注"未核验"
