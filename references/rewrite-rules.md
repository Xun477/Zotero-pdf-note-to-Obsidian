# 改写规则（Rewrite Rules）— 结构化笔记必做清单

> 在按模板改写 MD 时，**同时遵守**以下规则。模板（resources/template/paper.md、general.md）定义"输出长什么样"，本文件定义"改写时必须做到什么"。两者冲突时以本文件为准。

## Frontmatter 必填

按模板顶部 YAML 字段生成，**逐字段提炼为一句话**，**不得机械复制摘要大段文字**；数值必须来自原文。`zotero_key` 取 pipeline_prep.py 输出 JSON 的 `item_key`。

## 一句话摘要必填

正文首块，用 **1 句话**写清"**对象/器件 → 方法 → 关键结论**"。必须通顺、独立可读（Obsidian 列表/卡片视图会直接展示）。

## 原文引用规则

- 结果/结论区的**每一条"主要发现"必须紧邻至少一条真实原文引用**（注明出处，如 PDF 第 n 页）。
- 引用必须**真实出现在** MinerU MD 或原 PDF 中。
- **定位不到原句时写「未在当前全文中定位到可核验原句」**，严禁根据中文摘要反向生成英文 quote，严禁编造页码。
- 页码仅在可靠映射时写；不确定就只保留原文引用不写页码。

## 公式规则

- 公式**仅原文可靠时保留**，结构为"公式说明 + 公式 + 公式拆解"（说明做什么用，拆解符号含义/对应步骤）。
- 乱码/残片**不强行解释**，也不为占位符编造符号拆解；没有可靠公式就不写这一节。

## 「我的判断」必填

笔记结尾的 `## 我的判断` 四问**必须填写**：
- 最有启发的点 / 可借鉴的方法 / 可继续追问的问题 / 与我的研究关联

## 证据分层

- 原文（MinerU MD / 原 PDF）= **证据层**；笔记 = **理解层**。性能数值、公式、引语**必须回原文核对**，不得凭空转述。
- **AI 转述用普通正文，原文引用用引用块 `>`**，两者不混写。
- 无法核验的内容明确标注"未核验"，不得伪装成原文。
