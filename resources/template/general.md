# General 模板 — 非论文文献（综述 / 应用笔记 / 技术报告 / 专利 / 白皮书）

适用：综述（Review）、Application Note、技术报告、专利、白皮书等非原创研究论文。

---

## Frontmatter（必填）

顶部写入提炼性 YAML frontmatter（每字段一句话，不得机械复制摘要）：

```yaml
---
title: "{标题}"
tags:
  - 文献笔记
  - {领域标签}
source: "{来源}"
author: "{作者}"
year: "{年份}"
doi: "{DOI}"
type: "{类型：Review / Application Note / 技术报告 / 专利 / 白皮书}"
zotero_key: "{item_key}"
theme: "一句话：本文解决什么问题"
method: "一句话：核心方法/技术/综述视角"
key_finding: "一句话：最关键结论/要点"
relevance: "一句话：与我研究的关联"
---
```

---

## 核心原则

**不设固定板块。** 按 PDF 自身章节结构逐步总结，原文有什么就归纳什么，不要强行套用 IMRaD 框架。

## 改写规则

1. **保留每一条** `![](images/xxx.png)` 图片引用和论文元数据（标题、作者、来源、年份、类型），**一条都不许丢**
2. **用自己的话概括**每章/每节的核心内容，删除原文段落
3. **所有**图片引用都移到对应内容附近，上方加描述性标题（如 `**Figure 1:** xxx`）；放不下的图追加到文末 `## 全部图片 / 图片附录` 一节
4. **直接用原始路径**，不需要重命名或创建新目录
5. **读到 `## References` / `# References` / `参考文献` 立即停止**，删除参考文献列表
6. **删除 Acknowledgements / 致谢**
7. **改写完成后逐条核对**：原文每一条 `![](images/xxx.png)` 都必须出现在新笔记（正文或附录）中，缺失即视为错误

## 输出结构

按原文实际章节顺序组织，但以下要素**必须出现**：

- **文章首部**：Frontmatter + 标题 + 信息行（`**作者:** ... | **来源/年份:** ..., {年份} | **DOI:** ...`）+ 类型标签
- **`## 一句话摘要`**：用 1 句话概括本文核心（对象/范围 → 方法/视角 → 关键结论）
- **关键结论 + 原文引用成对**：重要结论尽量配真实原文引用（注明出处）；定位不到写「未在当前全文中定位到可核验原句」，严禁反向生成 quote
- **`## Conclusion / 结论与个人评注`**：作者结论 + 局限/未覆盖内容 + 个人评注
- **`## 我的判断`**：最有启发 / 可借鉴 / 可继续追问 / 与我的研究关联
- **公式处理**：原文有公式且可靠才保留（说明 + 公式 + 拆解），乱码/残片不强行解释
- **尾部标注**：`> 本文由 MinerU 提取 + AI 整理` + `> 图片目录: images/`

中间内容自由组织，按原文章节逐节归纳即可；综述按 **综述范围与框架 → 各子领域逐节 → 研究趋势与开放问题** 组织。

```markdown
# {标题}

---

## 一句话摘要
{对象/范围 → 方法/视角 → 关键结论}

## {按原文章节归纳}
（每节：核心内容概括；关键数据/结论尽量配原文引用）
- **关键结论 1：** ...
- **原文引用 1：**
> "原文"（PDF 第 n 页）

（综述变体：`## 综述范围与框架` → `## {子领域 1}` → `## {子领域 2}` → `## 研究趋势与开放问题`）

## Conclusion / 结论与个人评注
**作者结论：** ...  **局限：** ...  **个人评注：** ...

## 我的判断
- **最有启发的点：** ...
- **可借鉴的方法：** ...
- **可继续追问的问题：** ...
- **与我的研究关联：** ...

---

> 本文由 MinerU 提取 + AI 整理
> 图片目录: `images/`
```

## 作者背景

- Application Note / 技术报告 / 专利 → **不搜 H-index**，仅根据单位信息简评
- 综述 → 跳过 H-index（作者数通常过多），根据单位 + 发表记录简评

## 尾部

若正文放不下的图片，在 `## Conclusion` 之后、上方 `---` 与尾部标注之前加入 `## 全部图片 / 图片附录`，列出剩余图片。
