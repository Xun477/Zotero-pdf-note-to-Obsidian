# General 模板 — 非论文文献（综述 / 应用笔记 / 技术报告 / 专利 / 白皮书）

适用：综述（Review）、Application Note、技术报告、专利、白皮书等非原创研究论文。

---

## 核心原则

**不设固定板块。** 按 PDF 自身章节结构逐步总结，原文有什么就归纳什么，不要强行套用 IMRaD 框架。

## 改写规则

1. **保留每一条** `![](images/xxx.png)` 图片引用和论文元数据（标题、作者、来源、年份、类型），**一条都不许丢**
2. **用自己的话概括**每章/每节的核心内容，删除原文段落
3. **所有**图片引用都移到对应内容附近，上方加描述性标题（如 `**Figure 1:** xxx`）；放不下的图追加到文末 `## 📷 全部图片 / 图片附录` 一节
4. **直接用原始路径**，不需要重命名或创建新目录
5. **读到 `## References` / `# References` / `参考文献` 立即停止**，删除参考文献列表
6. **删除 Acknowledgements / 致谢**
7. **改写完成后逐条核对**：原文每一条 `![](images/xxx.png)` 都必须出现在新笔记（正文或附录）中，缺失即视为错误

## 输出结构

按原文实际章节顺序组织，但以下三个要素**必须出现**：

- **文章首部**：标题 + 作者 + 来源/年份 + 类型标签
- **结尾**：`## 🏁 Conclusion / 结论与个人评注`（作者结论 + 局限/未覆盖内容 + 个人评注）
- **尾部标注**：`> 📝 本文由 MinerU 提取 + AI 整理` + `> 📁 图片目录: images/`

中间内容自由组织，按原文章节逐节归纳即可。以下为两个示例结构：

### 示例 A：应用笔记/技术报告

```markdown
# {标题}
**作者:** ... | **来源/年份:** ... | **类型:** Application Note

---

## 📝 Overview / 概述
（交代背景、本文目标、核心结论预览）

## 🔧 技术原理 / 方法
（按原文章节归纳）

## 📊 关键数据 / 验证
（图表 + 数据解读）

## 🏁 Conclusion / 结论与个人评注
**作者结论：** ...  **局限：** ...  **个人评注：** ...
```

### 示例 B：综述

```markdown
# {标题}
**作者:** ... | **期刊/年份:** ... | **类型:** Review

---

## 📝 综述范围与框架
（覆盖哪些子领域、时间跨度、文献筛选标准）

## {子领域 1}
...

## {子领域 2}
...

## 🔮 研究趋势与开放问题
...

## 🏁 Conclusion / 结论与个人评注
**综述价值：** ...  **个人评注：** ...
```

## 作者背景

- Application Note / 技术报告 / 专利 → **不搜 H-index**，仅根据单位信息简评
- 综述 → 跳过 H-index（作者数通常过多），根据单位 + 发表记录简评

## 尾部

若正文放不下的图片，在 `## 🏁 Conclusion` 之后、上方 `---` 与尾部标注之前加入 `## 📷 全部图片 / 图片附录`，列出剩余图片。

```markdown
---

> 📝 本文由 MinerU 提取 + AI 整理
> 📁 图片目录: `images/`
```
